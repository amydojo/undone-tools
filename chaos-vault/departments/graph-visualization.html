DEPT · CV-GRA · 3 PARTS

Graph Visualization

A three-layer composable graph model for knowledge and activity data. Layers can be toggled independently: a chronology spine, same-type clusters, and semantic idea→action→insight chains.

3 Experimental
Provenance
Donor · Living Tapestry

Living Tapestry was a personal knowledge and activity tracker that visualized journal entries, tasks, and reflections as an interconnected graph. The key insight was that three distinct relationship types (when things happened, what type they were, and how they related semantically) could be layered onto the same set of nodes without conflating the different lenses. Each layer answers a different question: the chronology layer answers "when?", clusters answer "how many of this type?", and semantic chains answer "what led to what?"

⚠
Experimental — No Production Deployment This reconstruction is based on the observed model, not a tested implementation. The Canvas rendering demo below is a simplified proof-of-concept. A production graph would require a proper layout algorithm (force-directed, hierarchical, or radial) and interactive hit-testing. D3.js or Sigma.js are natural fits for extending this.
The Three-Layer Model
1
Chronology Spine — CV-GRA-001
A linear timeline of all nodes ordered by creation date. Edges connect temporally adjacent events. This layer answers "what happened in sequence?" and is the structural backbone the other layers attach to.
Experimental
2
Same-Type Clusters — CV-GRA-002
Groups of nodes sharing a type (Idea, Action, Insight, Reflection) are drawn as weighted clusters. The cluster radius scales with the node count. This layer answers "where is attention concentrated?"
Experimental
3
Semantic Chain — CV-GRA-003
Directed edges expressing Idea→Action, Action→Insight, and Insight→Idea relationships. This layer answers "what caused what?" and is the most application-specific of the three — the edge types must be defined by the caller.
Experimental
Live Demo — Toggle Layers

Toggle each layer independently. The canvas re-renders to show only the active layers.

CV-GRA · Three-Layer Graph Model
Data Model 
// CV-GRA · Node and Edge Schema

Node {
  id:        string
  type:      'idea' | 'action' | 'insight' | 'reflection'
  label:     string
  createdAt: Date          // used by Layer 1 (chronology)
  cluster?:  string        // used by Layer 2 (cluster ID)
}

Edge {
  from:  string            // Node ID
  to:    string            // Node ID
  layer: 'chronology' | 'cluster' | 'semantic'
  rel?:  'idea_to_action' | 'action_to_insight' | 'insight_to_idea'
}

// Renderer receives { nodes, edges, activeLayers }
// and draws only edges matching active layers
