Camera

Cross-browser mobile camera capture behavior. Handles permission negotiation, fallback ladders, and canvas frame extraction cleanly across iOS Safari, Android Chrome, and desktop.

Reconstructed 1 Experimental
Provenance
Donor · Let's Glo

The camera pipeline was the core input mechanism of Let's Glo, a skin-analysis prototype. The clean-room extraction preserves the browser compatibility logic and state machine, while quarantining the Smooth MD scoring layer that sat downstream. The getUserMedia constraint profile and the canvas drawImage + toBlob capture pattern are the portable parts. Everything after "image captured" is intentionally excluded here.

CV-CAM-001

getUserMedia Permission Flow

Reconstructed
Use casesAny feature requiring camera input: vision analysis, document scan, QR, selfie capture.
Dependenciesnavigator.mediaDevices.getUserMedia — available in all modern browsers. Requires HTTPS or localhost.
Constraint profile{ video: { facingMode: { ideal: "environment" } }, audio: false } — requests rear camera on mobile, falls back to any available camera.
RiskLow. Behavior is browser-standard. Permission UI is entirely OS/browser-controlled.
CONTRACT SKETCH — PERMISSION FLOW 
// CV-CAM-001 · getUserMedia Permission Flow
// Clean-room behavioral reconstruction. Not copied from source.

async function requestCameraPermission() {
  // 1. Environment check — fail fast on unsupported browsers
  if (!navigator.mediaDevices?.getUserMedia) {
    return { ok: false, reason: 'unsupported' }
  }

  try {
    const stream = await navigator.mediaDevices.getUserMedia({
      video: { facingMode: { ideal: 'environment' }, width: { ideal: 1280 } },
      audio: false
    })
    return { ok: true, stream }

  } catch (err) {
    // Map to stable error types — do not leak raw DOMException
    const reason = {
      NotAllowedError:        'denied',
      PermissionDeniedError:  'denied',
      NotFoundError:          'no_camera',
      OverconstrainedError:   'overconstrained',
    }[err.name] ?? 'unknown'

    return { ok: false, reason }
  }
}

// Always stop tracks when done — prevents indicator staying on
function releaseStream(stream) {
  stream?.getTracks().forEach(t => t.stop())
}
CV-CAM-002

Canvas Frame Capture

Reconstructed
Use casesExtracting a still frame from a live video stream into a Blob or DataURL for upload.
DependenciesHTMLVideoElement, HTMLCanvasElement, canvas.toBlob()
MIME outputimage/jpeg at 0.92 quality — balances file size with vision model input requirements.
RiskLow. Canvas taint security applies if source video is cross-origin — not relevant in this usage.
CONTRACT SKETCH — FRAME CAPTURE 
// CV-CAM-002 · Canvas Frame Capture

function captureFrame(videoEl, options = {}) {
  const { quality = 0.92, mime = 'image/jpeg' } = options
  const canvas = document.createElement('canvas')
  canvas.width  = videoEl.videoWidth
  canvas.height = videoEl.videoHeight

  const ctx = canvas.getContext('2d')
  ctx.drawImage(videoEl, 0, 0)

  return new Promise((resolve, reject) => {
    canvas.toBlob(
      blob => blob ? resolve(blob) : reject(new Error('toBlob returned null')),
      mime,
      quality
    )
  })
}

// Usage
const blob = await captureFrame(videoElement)
const formData = new FormData()
formData.append('image', blob, 'capture.jpg')
