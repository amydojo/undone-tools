Continuity and Control

Patterns for carrying context across time and for making every consequential action explain what it understands, what it will do, and how recovery works.

6 Continuity systems4 Control principles
Continuity Position
Remember softly, preserve deliberately

Continuity is not infinite memory. The system carries the smallest useful context, distinguishes source from inference, exposes change over time, and gives the user control over what persists, expires, restarts, or disappears.

CV-CON-001

Emotional Continuity Envelope

Carry forward only the context needed for the next interface to respect what happened and what capacity remains. The completed artifact and the temporary task context remain separate.

ContainsUser-designated task, verified facts, declared needs, consent timestamp, expiry.
ExcludesPermanent emotional profile, unrelated receipt content, automatic continuation.
ControlsInspect, edit, clear now, expire, return to artifact.
CV-CON-002

Object Continuity System

Preserve an ordinary object as a future artifact by retaining its specimen, source capture, context, material changes, and rediscovery history.

LoopCapture → lock object field → preserve → generate artifact → archive → rediscover.
Truth layersSource, user context, manual selection, observation, generated metadata.
RiskContinuity scores or generated histories presented as objective fact.
CV-CON-003

Pattern Memory Over Daily Scoring

Mirror replaces daily performance with soft pattern recognition. A few check-ins become weather, not a grade. Similar days, possible contributors, and what helped afterward are presented tentatively.

PreferObservation, recurrence, context, and small nonurgent next moves.
BanStreaks, wellness scores, diagnosis, urgency, optimization pressure.
LanguageClear / likely / possible; “still taking shape”; user correction.
CV-CON-004

Thought-to-Action Topology

Living Tapestry’s accidental graph invention combines a chronological spine, same-type clusters, and idea-to-action-to-insight chains. Each edge type communicates a different kind of continuity.

LayersSequence, recurrence, semantic chain.
RequiredExplain edge provenance and allow manual correction or removal.
QuarantineLinking unrelated entries by array position and presenting the result as psychological meaning.
CV-CON-005

Procedural Accompaniment

KEYS reframes housing as more than search. The interface remains beside the person through discovery, risk evaluation, budgeting, paperwork, waiting, and response.

StagesDiscover → evaluate → avoid scams → budget → apply → wait → respond.
ValueOrientation, continuity of documents, deadlines, risks, and next requirements.
RiskOutdated eligibility, legal, financial, or listing data presented as verified.
CV-CON-006

Delta Over Score

Face Value and Mirror point toward longitudinal evidence that compares a person with their own prior observations instead of assigning a universal beauty, health, mood, or performance score.

ShowWhat changed, capture comparability, missing data, confidence, timeline.
Do not showAttractiveness grade, health diagnosis, universal “good skin” score.
UsePersonal evidence, product reaction history, condition changes, self-correction.
Control Behavior
CV-CTL-001

A Control Is a Contract

A control communicates what it understands, what it will do, the consequence of activation, and how reversible the result is. It is a negotiation, not just a decorated tap target.

BeforeName the action and consequence.
DuringKeep target stable and state legible across input modalities.
AfterConfirm result and keep recovery reachable.
CV-CTL-002

Friction Matches Consequence

Public, destructive, financial, privacy, and safety actions should not feel identical to reversible ones. Friction is proportional, accessible, and used for informed agency rather than obstruction.

Low consequenceImmediate action with ordinary undo.
High consequencePreview, deliberate commitment, confirmation, recovery where possible.
NeverUse friction to trap cancellation or punish a user for leaving.
CV-CTL-003

Recovery Attached to Action

The original target becomes its own undo window or keeps recovery spatially adjacent. The user should not need to hunt through history or settings to repair the action they just took.

PlacementSame region, immediate temporal window, visible final state.
AccessibilityUndo at least as reachable as the original action.
ExampleBad Day Receipt release confirmation with bounded undo.
CV-CTL-004

State Without Spectacle

Readiness, listening, processing, completion, and uncertainty use restrained material behavior without becoming the main event. Motion supports state but never carries it alone.

SignalsText label, shape, position, progress, restrained rhythm.
RequirementsReduced-motion substitute, stable layout, non-motion cue.
Retire whenThe behavior is merely delightful and does not reduce ambiguity, effort, or recovery cost.
